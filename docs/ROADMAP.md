# Dairy Farm Management System Roadmap

## Phase 1: Foundation

- Initialize Next.js, React, Tailwind CSS, TypeScript, and Firebase.
- Create the first mobile-first layout.
- Decide Firestore collections and access roles before building forms.

## Phase 2: Cow Profiles MVP

- Add cow list page.
- Add cow profile form.
- Add cow detail page with history sections.
- Store cow records in Firestore.

## Phase 3: Farm Records

- Add milk production records.
- Add medicine and vaccination records.
- Add pregnancy tracking.
- Add expenses and worker records.

## Phase 4: Reports And Deployment

- Add reports and analytics.
- Add admin and viewer permissions.
- Add Firebase security rules.
- Deploy to Vercel.
